# Orbital Academy

## Project Brief
Orbital Academy is an XR experience for Meta Quest that teaches the user about the solar system. The user explores the planets in their own room, completes missions and takes a quiz to test what they learned.

## What will the user learn?
The user will learn facts about our solar system including the Sun and the eight planets, their order, their sizes and what makes each planet unique.

## How will they learn it?
The experience takes place in the user’s own room via passthrough with a model of the solar system hovering in front of them. The user can grab a planet to bring it closer and see a fact panel about it, with voiceover, which is where they learn the facts. They then use what they have learned in short, simple missions such as placing the planets around the Sun in the right order, finding the planet that matches a clue like “the planet with rings” and lining the planets up from biggest to smallest. Finally a multiple choice quiz in 3D UI checks what the user has learned giving feedback after each answer and a final score.

## Technology
The project will be built in Godot 4 and deployed to Meta Quest. It uses Godot OpenXR Vendors for passthrough and Godot XR Tools for grabbing, pointing and 3D UI, along with Godot systems including GDScript, signals, timers, tweens, particles and spatial audio.
